1.1.0

Requires IntelliJ IDEA or Android Studio 2026.1 or newer.

  • Public catalogs no longer ask for a password when an artifact is missing
  • Compose Multiplatform versions stay on the JetBrains line, not the AndroidX line
  • Shared catalog keys recommend only a version that exists for every library using the key
  • Inlay hints always show the target version, including prereleases
  • Right-click an inlay to pick a version
  • SDK, NDK, and JDK toolchain keys get their own update suggestions
  • Module map edges stay visible while panning, and the map exports to PNG
  • Local MCP server so agents can ask what is safe to update
  • Error reports include a redacted action history and open a GitHub issue

1.0.0

Initial release of LibsHelper for Android Studio and IntelliJ.

Library inventory and updates

  • Reads declared libraries from gradle/libs.versions.toml and Gradle build files
  • Checks Maven Central, Google Maven, and the Gradle Plugin Portal first
  • Uses a project backup or private catalog only when an official catalog does not answer
  • Recommends the newest regular stable version, with an Update action that writes it into the catalog or build file
  • Shows RC, Beta, Alpha, and Snapshot versions separately; they are not treated as a replacement for the regular release
  • Search, an “only with updates” filter, and a full All libraries inventory (including libraries that are already current)
  • Shared catalog versions: one change updates every library that uses the same version key
  • Detects local AAR and JAR files alongside Maven coordinates

Analytics and sources

  • Counts for libraries, module uses, outdated libraries, and modules
  • Sunburst of the heaviest third-party libraries
  • Interactive module map (Gradle / Android / JVM / KMP / Wasm / common): zoom, pan, and search that jumps to a module
  • Where we look: official catalogs versus project backup or private sources, with sign-in when a catalog asks for it

Editor and settings

  • Inlay hints in version catalogs and build files: the next stable version next to the declaration (click opens LibsHelper)
  • Right-click a library declaration and choose Open in LibsHelper
  • Private catalogs: login, token, or a custom header; secrets stay in the IDE Password Safe
  • English and Russian UI, switchable in Settings without restarting the IDE
  • Check again ignores the cache and queries catalogs from scratch
